Treat the HTTP status as the primary category; do not rely on a nested upstream provider error or exact message wording.HTTP status codes#400 / 422Invalid requestCheck JSON, field names, supported controls, and input limits. Correct the request rather than retrying unchanged.401 / 403Authentication or accessCheck the key, account access, and whether credentials were revoked. Do not retry indefinitely.402Insufficient creditsCheck account credits and billing settings before submitting more work.409Request conflictAn attempt may still be running, the payload may not match the key, or the attempt may have ended. Preserve the original key and inspect retryAsNew.413Body too largeReduce the JSON body, including base64 image or PDF data. The account gateway accepts a 3.5 MB body; the engine behind it takes up to 23.4 MB when the request carries a PDF (16 MB decoded per file), but the gateway's limit is met first.429Concurrency limitQueue work and retry with bounded backoff. Do not assume Retry-After is always supplied.5xxService or upstream failureRetry transient failures within a bounded budget unless retryAsNew says the attempt ended. Record the request ID for support.A pipeline answers 200 whenever at least one step answered, so read each entry in steps: a failed step carries its own status and error in place, and a 422 from inside a step prefixes its loc with body.steps[i].<endpoint>. With on_error: "continue", the default, the next step still runs; with on_error: "stop" the first failure ends the pipeline and the later steps come back as skipped. When no step answered, the response takes the first failure’s status with its detail and every step’s entry, and nothing is billed.Timeouts and recovery#The account gateway allows up to 110 seconds for a model request. The published SDKs use longer per-attempt client timeouts: 130 seconds in Python and 120 seconds in JavaScript. Retries can extend total elapsed time beyond one attempt.A browser or client timeout does not prove that the backend stopped. Do not generate a new key merely because your UI stopped waiting. Keep a recoverable job state and retry the original attempt before offering an explicit new run.Request cancellation, retry, and business approval are separate concerns. Your application should prevent duplicate downstream actions even when it replays a successful API response.New to Clocked?Start with a request →

 Documentation API & SDKsBrowse documentation Get an API key POST/clocked/pipelineTextUse Pipeline when one text needs more than one endpoint, in order: find the personal data and check for an injection before Decide routes a message, or extract a document's fields and verify an answer against it in the same call. Protect flags when it finds any entity, whatever its kind, so name the kinds that should stop the pipeline in that step's entities. Guard and Inspect flag a verdict other than benign, Verify a verdict other than supported, Compare a conflict. With on_error: "stop", the first failure ends the pipeline the way a flagged guard does, and stopped.reason is error.Steps run one after another, never side by side. Each is dispatched in-process to its endpoint's own route, so it is validated, read, and answered exactly as the endpoint answers it alone. Every step reads the same text; one step's answer is not passed to the next.Limits#Each limit below is a 422 unless stated, and the error names the step.Steps1–16One endpoint per step. This is not end-to-end round-trip latency.X-Clocked-CreditsHTTP response headerThe credits settled for this request: the model time at 25 ms a credit, rounded up, at least 1.X-Clocked-Cost-UsdHTTP response headerWhat those credits cost in dollars, to six decimals. Credits within the period's remaining allowance are priced at the plan's prepaid rate, the monthly price spread over the monthly allowance (Build $0.24, Production $0.20, Scale $0.15 per 1,000); credits beyond it at the plan's flat overage rate ($0.30, $0.25, $0.20 per 1,000).X-Clocked-Cost-BasisHTTP response headerprepaid, overage, mixed (the request crossed the allowance), or reference: a trial has no price of its own, so the figure is what the same request costs on Production, and nothing is charged.X-Clocked-TransportHTTP response headerHow the engine was reached (door:east, door:west, direct), or replay when the answer came from the ledger.
