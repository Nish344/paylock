Docs/API reference
Fill API
Combine extracted facts, decisions, scores, and explicitly requested generated text in one record.
POST/clocked/fillText + images
Use Fill when a record needs more than one output type. Define each field according to the job it performs rather than asking for one large prose response.
Before you send a requestAuthenticate with an account API key and provide a unique idempotency key. The fields below describe text requests. Image requests have a different response contract.
Request body#
Send a JSON object to https://clocked.rezolve.ai/clocked/fill.
textstringConditionalNon-empty source text. Source, instructions, fields, and generated output share the serving context. Required unless pdf is sent.
pdf / pages / pdf_mode / return_textstring / integer[] | string / "auto" | "text" | "image" / booleanA PDF, as base64 or a data:application/pdf;base64 URL, in place of text; the pages to read ([1, 3] or "1-3,5"); auto, text, or image reading; and whether to return the text the PDF was read as. See PDF input.
fieldsobject<string, typed field>Required1–64 named field definitions. Every field has a type.
instructionsstringShared reading rules or application policy. Maximum 20,000 characters. Keep source content in its source field, not in these instructions.
reference_datestring · YYYY-MM-DDAnchor for relative dates in generated date fields.
return_pdf"highlight" | "box" | "redact"Mark the answer's spans in the PDF and return the marked copy in pdf.marked.document. Text mode only. See Marking the answer back into the PDF.
Six field types#
extractsource valuedescription, list, max_items, infer, format, region, and unit. infer defaults to true; explicitly set infer: false when the record must contain strictly verbatim evidence.
choicesingle labeloptions: 2–255 distinct labels. Can instead use options_by for conditional options. allow_none permits no selected option.
multiselectmultiple labelsoptions: 2–64 distinct labels. threshold defaults to 0.5; labels are evaluated independently.
scoreordered levellevels: 2–10 distinct labels from lowest to highest. Returns the selected value, probabilities, and expected score.
yes_nobooleanUse description to define the yes/no judgment. Returns value and the available probability/confidence information.
generatewritten or normalized valueExplicitly requests generation. format: text, date, or number. max_tokens: 1–400, default 40. Generated values are marked source: generated.
Field controls#
descriptionstringWhat the field should mean. Defaults to the field name.
inferboolean · extractDefault: trueFalse requires a verbatim source value; true allows an inferred/generated fallback.
list / max_itemsboolean / integer · extractCollect values. The published SDK/playground supports max_items from 1–32.
region[start, end] · extractRestrict the text read to a non-empty character range within the source. End is exclusive.
unit"sentence" · extractRead a sentence-sized source unit.
formatstringExtract: text, integer, number, date, email, phone, url, code. Generate: text, date, number. Formatted/inferred values are not interchangeable with verbatim source spans.
temperaturenumber · 0.5–50Readout probability softness for decision fields.
rotationsinteger · 1–8Number of option orderings to evaluate. More orderings can increase work and latency.
options_byobject · choiceUse {field: "parent", "parent answer": ["option A", "option B"]}. The parent must be a different choice or yes_no field. Each branch needs 2–255 options. Do not create cyclic dependencies.
Read each field according to its type#
The result lives under fields, keyed by the names you supplied. value can be a string, number, boolean, array, or null. Decision fields can include probabilities; source reads can include offsets and confidence; generated fields include source.
Do not require every field to have every metadata key. In particular, do not use a generated value as if it were a verbatim quotation, and do not interpret verification confidence as a guarantee that a generated answer is correct.

Response body#
A successful HTTP request returns the endpoint result directly. Fields described as optional may be absent. Do not require diagnostic keys to consume a result.
modelstringModel identifier.
fieldsobject<string, filled field>Per-field value plus type-dependent metadata: probabilities, confidence, expected, source, or text offsets.
pdfobject · PDF requestsThe page count, the pages read, the reading mode and, in text mode, page_offsets for finding the page of an offset. With return_pdf, marked. See PDF input.
timingobjectOptional engine timing. Keys vary by endpoint and execution path. Use HTTP response headers for gateway and billable model timing, not a fixed sum of these values.

Image input#
Supply images and 1–16 fields. result contains typed values without text-mode probabilities or source offsets. Do not send region, unit, temperature, rotations, threshold, options_by, allow_none, or max_tokens in image field definitions.
Image request and response reference Integration notes#
Use Extract instead if every output must be a verbatim fact.
Generated fields introduce generation work. The non-generative decision/extraction behavior does not mean a requested generate field avoids text generation.
