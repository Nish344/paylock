Docs/API reference
Decide API
Answer named questions with typed decisions and the probabilities behind them.
POST/clocked/decideText + images
Use Decide when your software needs to route, classify, approve, prioritize, or select labels. Use Extract when you need the exact words from the source; use Fill to combine both in a record.
Before you send a requestAuthenticate with an account API key and provide a unique idempotency key. The fields below describe text requests. Image requests have a different response contract.
Request body#
Send a JSON object to https://clocked.rezolve.ai/clocked/decide.
statestring | object | arrayConditionalShared context for questions. Required unless every question names a document or pdf is sent in its place. An empty string, object, or array is allowed: the model answers from the question alone, not from case evidence.
pdfstringA PDF, as base64 or a data:application/pdf;base64 URL, in place of state. It is read as text or as page images. See PDF input.
questionsobject<string, question>RequiredNamed questions. Each definition needs a type and the controls described below. Names are preserved in answers.
instructionsstringShared reading rules or application policy. Maximum 20,000 characters. Keep source content in its source field, not in these instructions.
calibration_temperaturenumber · 0.5–50Default: 4Controls probability softness. This is calibration, not a text-generation temperature.
rotationsinteger · 1–8Number of option orderings to evaluate. More orderings can increase work and latency.
documentsarray<{id, text}>Optional per-document reads: 1–64 documents, unique IDs up to 128 characters, up to 20,000 characters per document and 400,000 total. Questions use document to name the document they read.
Question types#
type: "noul"yes / noUse instructions to ask the question, or criteria with true/false descriptions. Returns noul: the yes probability. An optional threshold (0–1) also returns decision and threshold.
type: "choice"one labelcriteria maps 2–255 distinct labels to descriptions. Returns choice, probabilities for the alternatives, and confidence.
type: "multiselect"multiple labelsUse criteria (label → description) or options (2–64 labels), not both. Each label is evaluated independently. threshold defaults to 0.5. Returns selected, probabilities, and threshold.
type: "score"ordered scalecriteria is an ordered array of 2–10 distinct levels, lowest first. Returns score (the probability-weighted zero-based index), legend, probabilities, and confidence.
instructionsstring · per questionDescribe the question and its decision rules.
documentstring · per questionID of one supplied document. That question reads only that document, not the shared state or the other documents. At least one question must name a document if documents is supplied.
Turn probabilities into application policy#
Multi-select probabilities are independent and do not need to sum to one. A single-choice distribution describes competing alternatives. Preserve that distinction when showing a confidence indicator.
A yes/no threshold adds a boolean; it does not change the underlying business policy for you. Your application decides whether to act, reject, or ask a person to review. For ambiguous categories, include an explicit “not established” option.
Document-scoped questions cannot infer relationships across other documents. Put cross-document context in state or use Compare. The serving context includes instructions and question branches; a character limit alone does not guarantee a request will fit.

Response body#
A successful HTTP request returns the endpoint result directly. Fields described as optional may be absent. Do not require diagnostic keys to consume a result.
modelstringModel identifier. This is not a deployment pin.
answersobject<string, answer>One typed answer for each question, keyed by your question names. See Question types for the returned keys.
usageobjectReported input_tokens and output_tokens. Token counts are not account credit usage.
pdfobject · PDF requestsThe page count, the pages read, the reading mode and, in text mode, page_offsets for finding the page of an offset. With return_pdf, marked. See PDF input.

Image input#
Supply images and up to 16 questions. result maps names to a boolean, label, array of labels, or score index. No text probability distributions, threshold decisions, document routing, calibration_temperature, or rotations.
Image request and response reference Integration notes#
An empty state is permitted only for Decide. It is useful for prior-only questions, not evidence about a missing case.
Evaluate calibration and thresholds on your own labels and data. A high probability can still accompany a wrong decision.
