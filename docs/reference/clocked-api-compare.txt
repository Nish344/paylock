Docs/API reference
Compare API
Find duplicates, overlap, and conflicts across a set of text documents.
POST/clocked/compareText
Use Compare when relationships between documents matter: reconciling terms, reviewing policy versions, or detecting repeated content. It reports every pair, with passages from both sides when available.
Before you send a requestAuthenticate with an account API key and provide a unique idempotency key.
Request body#
Send a JSON object to https://clocked.rezolve.ai/clocked/compare.
documentsarray<string | {id, text}>Required2–20 non-empty documents. Use unique IDs for unambiguous attribution. Maximum 200,000 characters and 58,000 tokens across the set; serving context also applies.
documents[i].pdfstringA document as a PDF: {id?, pdf, pages?, date?} in place of {id, text}, read as text. return_text is set once, at the top level. See PDF input.
return_pdf"highlight" | "box" | "redact"Mark the answer's spans in the PDF and return the marked copy in pdf.marked.document. Text mode only. See Marking the answer back into the PDF.
instructionsstringShared reading rules or application policy. Maximum 20,000 characters. Keep source content in its source field, not in these instructions.
thresholdnumber · 0–1Default: 0.5Minimum related probability for passage reads and roll-up membership. Not a generic confidence cutoff for every sub-result.
evidence"all" | "flagged" | "none"Default: "flagged"Controls which findings receive source passages. Evidence may be absent when no passage is found.
kindsbooleanDefault: trueClassify the kind of duplicate or conflict.
rotationsinteger · 1–8Default: AdaptiveNumber of option orderings to evaluate. More orderings can increase work and latency.
debugbooleanDefault: falseInclude diagnostic reads. Keep diagnostics out of end-user UI unless you deliberately interpret them.
Pair relationships and evidence#
With n documents there are n × (n − 1) / 2 pairs: 20 documents create 190 comparisons. Request size and evidence settings both affect work.
A document date or a differing number does not by itself establish a contradiction. Use instructions to define the same entity, period, and scope. Retain human review for document retirement or contractual conflicts.
a / bstringIDs of the two compared documents.
relationstringsame, overlapping, conflicting, or unrelated.
related / probabilitiesnumber / objectRelated probability and the distribution over relationship alternatives.
duplicates / conflictsfinding[]Every passage of the second document that states something the first also states, and every passage that disagrees with the first, each with its counterpart. Both lists are empty for an unrelated pair, and a pair can carry both: shared content on one fact and a conflict on another.
finding.kind / kinds / confidencestring / object / numberFinding type, its alternatives, and confidence when classification is enabled.
finding.a / finding.bsource passagePassages from each side: document, quote, start, end, confidence. Offsets are relative to each original document.

Response body#
A successful HTTP request returns the endpoint result directly. Fields described as optional may be absent. Do not require diagnostic keys to consume a result.
modelstringModel identifier. This does not pin a deployment.
verdictstringRoll-up such as conflicts, duplicates, or another overall outcome.
documentsarrayEach document’s IDs of duplicates, overlaps, and conflicts.
pairsarray of pair resultsThe pairwise relationship and available findings.
duplicates / overlaps / conflicts / related_pairsinteger[]Zero-based indexes into pairs—not document indexes.
threshold / evidence / instructions_usednumber / stringApplied settings.
stagesobject · optionalExecution diagnostics. Not a stable billing calculation.
pdfarray · PDF requestsOne object per PDF document, in request order, each naming its document: the page count, the pages read, and page_offsets for finding the page of an offset. See PDF input.
timingobjectOptional engine timing. Keys vary by endpoint and execution path. Use HTTP response headers for gateway and billable model timing, not a fixed sum of these values.

Image input#
Not supported. Use 2–20 text documents; do not send images or image-location controls.
Integration notes#
Compare accepts text documents, and a PDF per document, read as text. Convert anything else to text before calling it.
The SDK reference covers the stable public controls; engine-only experimental options are not an integration contract.
